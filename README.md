summer_paper
==============================


Information
-----------

Hello! These are the scripts used for the paper on ice-shelf viability.

This folder contains all scripts that were used for the data preparation, formatting and the final figures and analysis. You'll find associated data here: https://zenodo.org/records/18834321

For a cleaner repository, only having the final scripts for the figures, you can also check out this repository: [https://github.com/ClimateClara/scripts_for_review](https://github.com/ClimateClara/scripts_paper_iceshelf_viability) and the associated, already formatted data, here: https://doi.org/10.5281/zenodo.13768759.
